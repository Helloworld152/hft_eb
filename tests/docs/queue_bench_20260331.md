# Queue Benchmark 记录

日期：2026-03-31

## 测试方式

- 目录：`tests/`
- 构建方式：独立 `CMake` + `Release`
- 运行脚本：`tests/run_queue_bench.sh`
- 参数：
  - `total_ops = 4,000,000`
  - `capacity = 65,536`
  - `repeats = 5`

## 原始结果摘要

### MPSC 负载对比


| Producers | MPSC avg/best (Mops/s) | MPMC avg/best (Mops/s) | Avg Ratio |
| --------- | ---------------------- | ---------------------- | --------- |
| 1         | 101.77 / 122.05        | 66.30 / 66.71          | 1.53x     |
| 2         | 12.31 / 12.44          | 11.01 / 12.31          | 1.12x     |
| 4         | 16.11 / 17.16          | 9.10 / 9.81            | 1.77x     |
| 8         | 18.89 / 19.38          | 8.97 / 11.25           | 2.11x     |


### 单生产者对比


| Queue | avg/best (Mops/s) |
| ----- | ----------------- |
| SPSC  | 147.24 / 160.61   |
| MPSC  | 110.31 / 116.22   |
| MPMC  | 56.10 / 57.37     |


单生产者下的相对比值：

- `MPSC / SPSC = 0.75x`
- `MPMC / SPSC = 0.38x`
- `MPSC / MPMC = 1.97x`

## 结论

1. 单生产者场景下，性能关系符合预期：`SPSC > MPSC > MPMC`。
2. 多生产者场景下，当前 `MPSCQueue` 明显优于 `MPMCQueue`，尤其在 `4` 和 `8` 个生产者时提升明显。
3. 当前 `queue.h` 中的高性能实现整体表现正常，没有再出现此前“实现层次倒挂”的情况。

## 备注

- `1 producer` 下 `MPSC` 结果仍有一定抖动，但单生产者专项对比结果更稳定，可优先参考该段结论。
- 如果后续需要进一步提高结果稳定性，可继续补：
  - warmup
  - 线程绑核
  - 更细粒度的统计口径
