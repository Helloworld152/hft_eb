# 策略接口文档

## 策略基类 CtaTemplate

策略继承 `CtaTemplate`，入口文件：`hft_backtest/template.py`

```python
from hft_backtest import BacktestEngine, CtaTemplate

class MyStrategy(CtaTemplate):
    def __init__(self, engine, setting):
        super().__init__(engine, setting)
```

---

## 生命周期回调

| 回调 | 触发时机 | 参数 |
|------|----------|------|
| `on_init()` | 策略初始化，可做参数校验 | 无 |
| `on_start()` | 策略启动，可做状态初始化 | 无 |
| `on_stop()` | 策略停止，可输出统计 | 无 |

---

## 行情回调

### on_tick

逐笔行情，含五档盘口。回测 `data_mode="tick"` 时触发。

```python
def on_tick(self, tick: TickData):
```

**TickData 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `symbol` | str | 品种代码 |
| `last_price` | float | 最新价 |
| `volume` | int | 成交量 |
| `turnover` | float | 成交额 |
| `open_interest` | float | 持仓量 |
| `open_price` | float | 开盘价 |
| `highest_price` | float | 最高价 |
| `lowest_price` | float | 最低价 |
| `pre_close_price` | float | 昨收价 |
| `upper_limit` | float | 涨停价 |
| `lower_limit` | float | 跌停价 |
| `bid_price_1~5` | float | 买一到买五价 |
| `bid_volume_1~5` | int | 买一到买五量 |
| `ask_price_1~5` | float | 卖一到卖五价 |
| `ask_volume_1~5` | int | 卖一到卖五量 |
| `trading_day` | int | 交易日 YYYYMMDD |
| `update_time` | str | 更新时间 |

### on_bar

K 线行情。回测 `data_mode="bar"` 时触发。

```python
def on_bar(self, bar: BarData):
```

**BarData 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `symbol` | str | 品种代码 |
| `open` | float | 开盘价 |
| `high` | float | 最高价 |
| `low` | float | 最低价 |
| `close` | float | 收盘价 |
| `volume` | int | 成交量 |
| `turnover` | float | 成交额 |
| `open_interest` | float | 持仓量 |
| `interval` | str | K 线周期 |

## 回报回调

### on_order

报单状态变更时触发。每笔订单至少触发 2 次（报单 + 成交/撤单）。

```python
def on_order(self, order: OrderData):
```

**OrderData 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `symbol` | str | 品种代码 |
| `direction` | str | 方向: B(买) / S(卖) |
| `offset` | str | 开平: O(开仓) / C(平仓) / T(平今) |
| `price` | float | 报单限价 |
| `volume_total` | int | 报单总量 |
| `volume_traded` | int | 已成交量 |
| `status` | str | 状态: 0(全部成交) / 1(部分成交) / 3(已报) / 5(已撤单) |
| `order_ref` | str | 策略自定义引用号 |
| `order_sys_id` | str | 系统单号 (e.g. SIM1) |

### on_trade

每笔成交触发。

```python
def on_trade(self, trade: TradeData):
```

**TradeData 字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `symbol` | str | 品种代码 |
| `direction` | str | 方向: B(买) / S(卖) |
| `offset` | str | 开平: O(开仓) / C(平仓) |
| `price` | float | 成交价 |
| `volume` | int | 成交量 |
| `trade_id` | str | 成交编号 (e.g. T1) |
| `order_ref` | str | 对应报单引用号 |
| `order_sys_id` | str | 对应系统单号 (e.g. SIM1) |

---

## 下单方法

| 方法 | 说明 | offset_flag |
|------|------|-------------|
| `buy(price, volume)` | 买入开仓 | O |
| `sell(price, volume)` | 卖出平仓 | C |
| `short(price, volume)` | 卖出开仓 | O |
| `cover(price, volume)` | 买入平仓 | C |
| `send_order(symbol, dir, off, price, vol)` | 通用下单 | 自定义 |

参数：
- `price` (float) — 限价，传 0 为市价单
- `volume` (int) — 手数
- `symbol` (str, 可选) — 不传则用绑定的 vt_symbol

---

## 工具方法

| 方法 | 说明 |
|------|------|
| `write_log(msg)` | 输出 `[策略名] msg` 到终端 |
| `vt_symbol` | 绑定的品种代码，由 add_strategy 时的 setting 指定 |

---

## 最小示例

```python
from hft_backtest import BacktestEngine, CtaTemplate

class MyStrategy(CtaTemplate):
    def __init__(self, engine, setting):
        super().__init__(engine, setting)
        self.bought = False

    def on_tick(self, tick):
        if tick.symbol != self.vt_symbol:
            return
        if not self.bought and tick.last_price <= 100:
            self.write_log(f"买入 @{tick.last_price}")
            self.buy(price=tick.last_price, volume=1)
            self.bought = True
        elif self.bought and tick.last_price >= 101:
            self.write_log(f"卖出 @{tick.last_price}")
            self.sell(price=tick.last_price, volume=1)
            self.bought = False

    def on_order(self, order):
        self.write_log(f"报单回报 {order.direction}{order.offset} "
                       f"状态={order.status} 成交={order.volume_traded}/{order.volume_total}")

    def on_trade(self, trade):
        self.write_log(f"成交 {trade.direction}@{trade.price} vol={trade.volume}")

engine = BacktestEngine()
engine.set_parameters(
    data_mode="tick",
    data_file="data/market_data_20260523_night",
    symbols_file="conf/symbols.txt",
    initial_balance=1_000_000,
)
engine.add_strategy(MyStrategy, {"symbol": "au2606"})
result = engine.run_backtesting()
print(result.statistics)
```
