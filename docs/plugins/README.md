# 插件参数索引 (Plugin Parameters Index)

目的：提供一个统一入口，按插件列出参数说明文档。

## 规范
- 每个插件一个文档文件
- 文件名格式：`<plugin_id>.md`
- 文档内容必须遵循 `docs/插件参数说明规范_plugin_params.md`

## 索引

- `PyStrategy` → `py_strategy.md`
